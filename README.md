# Sub-Store 入口运营商与节点国旗

这是一个 Sub-Store 操作脚本，用于将节点名称改为：

```text
入口运营商 原节点国家国旗
```

示例：

- `电信 🇭🇰`
- `AWS 🇺🇸`
- `鹏博士 🇭🇰`

## 功能

- 根据节点服务器地址查询入口 ISP、组织、自治系统和云托管信息。
- 中国电信、中国联通、中国移动、广电、铁通和教育网统一显示为简短名称。
- 长城宽带、鹏博士、Dr.Peng 等统一显示为 `鹏博士`。
- 识别 AWS、Azure、Google Cloud、阿里云、腾讯云、华为云、Vultr、DigitalOcean、Hetzner、OVH 等云厂商。
- 从原节点名称提取国旗，也兼容常见国家代码和中文国家名。
- 默认启用按服务器地址缓存，减少重复查询。

## 使用

在 Sub-Store 前端的“脚本/操作脚本”中新建脚本，将 `entrance-isp-flag.js` 的内容粘贴进去，然后对订阅执行。

可选参数：

- `concurrency=5`：并发查询数。
- `timeout=5000`：请求超时，单位为毫秒。
- `retries=1`：失败重试次数。
- `cache=true`：启用缓存。
- `keep_original=true`：没有识别到原节点国旗时保留原名称。
- `api=...`：自定义接口地址，必须包含 `{{proxy.server}}`。

默认接口为 `ip-api.com`。免费接口有频率限制，节点数量较多时建议降低并发数。

## 注意

该脚本检测的是节点服务器的入口信息，不是代理实际访问网站时的落地或出口信息。默认查询地址使用 `ip-api.com`，如需更换服务，可通过 `api` 参数指定接口。
